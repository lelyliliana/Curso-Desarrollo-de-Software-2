# Ejemplo 01 - Fundamentos de HTML y CSS

## Unidad 2 - Introducción a las interfaces de usuario web

En esta unidad se retoman los fundamentos de **HTML y CSS** necesarios para construir interfaces web.

Como estos contenidos ya se encuentran desarrollados y documentados con ejemplos prácticos en el repositorio del curso **Lenguaje de Programación II**, no se duplicará el mismo código dentro de este repositorio.

El propósito es reutilizar esos recursos como base para continuar posteriormente con diseño responsivo, accesibilidad, manipulación del DOM, JavaScript moderno y React.

---

# Objetivo de aprendizaje

Al finalizar la revisión de estos recursos, el estudiante estará en capacidad de:

* reconocer la estructura básica de un documento HTML;
* utilizar etiquetas HTML para organizar contenido;
* crear enlaces, imágenes, listas, tablas y formularios;
* utilizar etiquetas semánticas;
* relacionar un documento HTML con una hoja de estilos CSS;
* utilizar selectores CSS;
* aplicar clases e identificadores;
* modificar propiedades visuales de los elementos;
* comprender conceptos básicos de distribución y diseño de interfaces.

# Relación entre HTML y CSS

De manera simplificada:

```text id="xhp0ox"
HTML
│
└── estructura y contenido

CSS
│
└── presentación y diseño
```

Por ejemplo, HTML puede definir:

```html id="27e5gi"
<h1>Desarrollo de Software II</h1>
```

mientras CSS puede definir cómo se visualiza ese elemento:

```css id="nmrrmh"
h1 {
    font-size: 2rem;
    text-align: center;
}
```

# ¿Por qué no se duplican los ejemplos?

Los contenidos de HTML y CSS ya cuentan con ejemplos independientes dentro del repositorio de Lenguaje de Programación II.

Copiar nuevamente esos archivos produciría:

* duplicación de código;
* repetición de documentación;
* mayor dificultad para mantener los ejemplos actualizados;
* diferentes versiones del mismo recurso en varios repositorios.

Por esta razón, en Desarrollo de Software II se reutilizarán esos recursos como material base.

# Antes de continuar

Compruebe que puede explicar con sus propias palabras:

1. ¿Qué función cumple HTML?
2. ¿Qué función cumple CSS?
3. ¿Qué diferencia existe entre una etiqueta HTML y una regla CSS?
4. ¿Para qué sirve el atributo `id`?
5. ¿Para qué sirve el atributo `class`?
6. ¿Cómo se relaciona un archivo HTML con un archivo CSS?
7. ¿Qué significa HTML semántico?
8. ¿Qué función cumplen etiquetas como `header`, `nav`, `main`, `section` y `footer`?

Si presenta dificultades con alguno de estos conceptos, consulte los ejemplos enlazados antes de continuar.
